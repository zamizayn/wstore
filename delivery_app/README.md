# Delivery App - WStore

A Flutter mobile app for delivery partners to manage their deliveries.

## Features
- Login with phone + password
- View assigned orders (New / Active / Delivered tabs)
- Accept / Pick Up / Deliver / Cancel orders
- View customer details and call them
- Open delivery address in Google Maps
- View order items, payment info, distance from branch
- Profile screen with logout

## Setup
1. Update `lib/config/api_config.dart` with your backend domain
2. Run `flutter pub get`
3. Run `flutter run`
